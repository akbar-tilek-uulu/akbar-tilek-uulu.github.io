The SIEM/SOC platform project

The principal independent project of Akhbar Tilek Uulu is a concept for a SIEM/SOC platform that unifies infrastructure monitoring, security event analysis, threat detection, machine learning and large language models within one system. It grows directly out of his interests in monitoring infrastructure, detecting threats, analysing security events and automating the work of a security operations centre.

The analytical layer is designed around a division of labour between two kinds of model. Random Forest is applied to the machine analysis and classification of events, where a structured statistical classifier is well suited to high-volume, feature-based decisions. Large language models are used for the intelligent processing and interpretation of security information, where the task is to summarise, explain or contextualise rather than to score.

Attack simulation is included alongside detection, which reflects a practical concern: a detection system can only be evaluated against activity it is meant to catch, so generating representative adversarial activity is part of building the platform rather than an afterthought. Taken together, the project is the clearest expression of how Akhbar Tilek Uulu approaches his field — a working system in which backend engineering, data infrastructure, machine learning and defensive security are components of one design rather than adjacent specialisms.

Security of cloud and virtual environments

The academic foundation of this area is Akhbar Tilek Uulu’s final qualification thesis at the International Information Technology University (IITU), on applying artificial intelligence methods to the monitoring and security of cloud and virtualised computing environments. The practical side rests on his infrastructure stack — Linux, Docker, VirtualBox, CI/CD and Cloudflare — because telemetry has to be collected from hosts, containers and virtualised environments before anything can be analysed.
